# eat-guide

다이어리 QR코드 연결용 고정 주소 저장소입니다.

- 고정 주소: https://sj-parkk.github.io/eat-guide/
- 연결 대상: 공공급식통합플랫폼 회원관리 운영지침 (구글 드라이브 PDF)

## 관리 방법
- PDF 내용 수정: 구글 드라이브에서 '파일 정보 → 버전 관리 → 새 버전 업로드' (이 저장소는 수정 불필요)
- 연결 대상 변경: `index.html`의 드라이브 링크 2곳을 수정 후 커밋

## 주의
- 저장소 이름·GitHub 사용자명·공개 설정을 변경하거나 저장소를 삭제하면 QR코드가 작동하지 않습니다.
