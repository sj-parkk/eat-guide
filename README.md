# eat-guide — 다이어리 QR 문서 연결 운영 가이드

다이어리에 인쇄된 QR코드로 공공급식통합플랫폼 지침·약관 PDF를 열람할 수 있도록 하는 **고정 주소 저장소**입니다.
이 문서 하나만 보고도 누구나 운영할 수 있도록 작성되었습니다.

---

## 1. 한눈에 보기

```
[다이어리 QR] → [GitHub 고정 주소 (절대 불변)] → [구글 드라이브 PDF (교체 가능)]
```

- QR코드에는 **GitHub 고정 주소**가 들어 있습니다. 인쇄 후에는 바꿀 수 없습니다.
- 고정 주소에 접속하면 **0초 만에 구글 드라이브 PDF로 자동 이동**합니다.
- 따라서 **PDF가 바뀌어도 QR은 그대로** 쓸 수 있습니다. 연결 대상만 바꾸면 됩니다.

### 용어 풀이
| 용어 | 설명 |
|---|---|
| GitHub(깃허브) | 파일을 인터넷에 저장·공유하는 서비스. 이 저장소가 올라가 있는 곳 |
| 저장소(Repository) | GitHub 안의 프로젝트 폴더. 여기서는 `eat-guide` |
| GitHub Pages | 저장소의 파일을 웹페이지로 무료 게시하는 기능. 고정 주소를 만들어 줌 |
| 커밋(Commit) | 파일 수정 내용을 '저장 확정'하는 것. 커밋해야 반영되며, 누가·언제·무엇을 바꿨는지 기록이 남음 |
| 리다이렉트(Redirect) | 접속하자마자 다른 주소로 자동 이동시키는 것 |
| 파일 ID | 구글 드라이브 링크 중 `/file/d/` 와 `/view` 사이의 긴 문자열. 파일마다 고유함 |

## 3. 작업별 절차

### 3-1. PDF 내용만 개정된 경우 ★ 가장 흔한 경우 — GitHub 작업 불필요
1. 구글 드라이브에서 해당 PDF를 **우클릭 → 파일 정보 → 버전 관리**
2. **새 버전 업로드** → 개정된 PDF 선택
3. 끝. 링크(파일 ID)가 그대로 유지되므로 QR·GitHub 모두 수정할 필요가 없습니다.

> ⚠️ **올바른 파일을 골랐는지 반드시 확인**하십시오. 다른 문서를 새 버전으로 올리면 QR에서 엉뚱한 문서가 열립니다.
> ⚠️ 기존 파일을 **삭제 후 새로 업로드하면 안 됩니다.** 파일 ID가 바뀌어 QR이 열리지 않습니다.

### 3-2. 연결할 PDF 파일 자체를 바꾸는 경우 (드라이브 링크가 달라진 경우)
1. 새 PDF의 공유 설정을 **'링크가 있는 모든 사용자 – 뷰어'** 로 지정하고 링크 복사
2. GitHub 저장소에서 해당 폴더(예: `term2`) → `index.html` 클릭
3. 우측 상단 **연필 아이콘(Edit)** 클릭
4. `https://drive.google.com/file/d/...` 로 시작하는 **링크 2곳을 모두** 새 링크로 교체
   - 11번째 줄 `url=` 뒤
   - 18번째 줄 `href="` 뒤
5. 우측 상단 **Commit changes** → 메시지에 변경 사유 입력(예: `이용약관 17차 개정본으로 교체`) → **Commit changes**
6. 1~3분 후 **4. 확인 절차** 진행

### 3-3. 새 문서를 추가하는 경우 (예: term4)
1. 저장소 첫 화면 → **Add file → Create new file**
2. 파일 이름 칸에 `term4/index.html` 입력 (슬래시(/)를 입력하면 폴더가 자동 생성됨)
3. `term1/index.html` 의 내용을 전체 복사해 붙여넣기
4. 드라이브 링크 2곳, `<title>` 문서명, 본문 안내 문구의 문서명을 새 문서에 맞게 수정
5. **Commit changes**
6. 목록 페이지에도 추가: `index.html` 편집 → 아래 한 줄을 기존 목록 밑에 추가 → Commit
   ```html
   <a href="term4/">새 문서명</a>
   ```
7. 이 README의 **2. 문서별 주소** 표에 한 줄 추가
8. QR 이미지 생성 → `qr/term4.png` 로 업로드 (QR에는 반드시 `https://.../eat-guide/term4/` 주소를 넣을 것)

---

## 4. 확인 절차 (모든 변경 후 필수)
1. 휴대폰 또는 PC의 **시크릿(비공개) 창**에서 고정 주소 접속 (로그인되지 않은 상태로 확인하기 위함)
2. **문서명이 맞는지** 확인 (다른 문서가 열리지 않는지)
3. 변경 직후 이전 문서가 보이면 1~3분 기다린 뒤 다시 확인 (게시 반영 시간)
4. 3분이 지나도 반영되지 않으면 저장소의 **Actions** 탭에서 실패(빨간 X) 여부 확인

---

## 5. 잘못 수정했을 때 되돌리기
1. 해당 `index.html` 파일 화면 → 우측 상단 **History(시계 아이콘)** 클릭
2. 수정 전 기록을 열어 **이전 드라이브 링크를 확인**
3. 3-2 절차대로 이전 링크로 다시 수정 후 Commit

---

## 6. 절대 하지 말 것 ⛔ (QR코드가 작동하지 않게 됨)
- 저장소 **이름 변경** 또는 **삭제**
- 저장소를 **비공개(Private)로 전환** — 무료 계정은 공개 저장소에서만 Pages가 작동함
- GitHub **사용자명 변경**
- `term1`, `term2`, `term3`, `inspection` **폴더 이름 변경·삭제**
- Settings → Pages 설정 해제
- 연결된 드라이브 PDF **삭제**, 또는 공유 설정을 '제한됨'으로 변경
